📋 Useful endpoints:
  - /playground    - Interactive testing interface
  - /health        - Health check endpoint
  - /metrics       - Prometheus metrics
  - /crawl         - Main crawling API endpoint
  - /schema        - API schema documentation

🔑 For LLM features, create a secret with your API keys:
  kubectl create secret generic crawl4ai-llm-env --from-env-file=.llm.env
  Then set crawl4ai.llm.enabled=true and crawl4ai.llm.existingSecret=crawl4ai-llm-env

⚙️  For custom configuration, create a configmap:
  kubectl create configmap crawl4ai-config --from-file=config.yml
  Then set crawl4ai.config.enabled=true and crawl4ai.config.existingConfigMap=crawl4ai-config
